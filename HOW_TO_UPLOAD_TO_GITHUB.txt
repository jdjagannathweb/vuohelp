VUO HELP - ONLY CHANGED FILES FOR GITHUB UPLOAD
====================================================================

Is folder me sirf wahi files hain jo aapke GitHub (origin/main) se
update ya add hui hain (Total Size: ~3.5 MB).

TARIKA 1: GITHUB WEBSITE SE DRAG & DROP (Subse Aasan)
--------------------------------------------------------------------
1. Browser me apna GitHub repository kholein:
   https://github.com/jdjagannathweb/vuohelp

2. Upar "Add file" button par click karein -> "Upload files" chunein.

3. Is folder (`C:\Users\Jagannath\Downloads\vuohelp_changed_files`) ke
   andar ki files aur folders (assets, js, css, index.html, sitemap.xml,
   robots.txt, etc.) ko select karke browser me drag & drop karein.

4. Niche "Commit changes" par click kar dein!

--------------------------------------------------------------------
TARIKA 2: TERMINAL / GIT COMMAND SE (1-Click Push)
--------------------------------------------------------------------
Agar aap terminal use karna chahte hain to VS Code ya PowerShell me
ye command run karein:

   git push origin main

Agar GitHub login maange to apna Personal Access Token (PAT) enter karein.
